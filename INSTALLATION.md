# Espace Mariage V7.5.3 PROD

Ce paquet est prévu pour un dépôt GitHub Pages séparé afin d'utiliser :
https://mariage.latelierfleursetsens.fr

1. Créer un nouveau dépôt GitHub, par exemple `espace-mariage`.
2. Mettre le contenu de ce dossier à la racine du dépôt.
3. Activer GitHub Pages sur la branche `main`, dossier `/ (root)`.
4. Dans Squarespace DNS, créer le CNAME `mariage` vers `latelierfleursetsens-create.github.io`.
5. Dans Firebase Authentication > Settings > Authorized domains, ajouter `mariage.latelierfleursetsens.fr`.
6. Dans GitHub Pages du nouveau dépôt, vérifier le domaine personnalisé `mariage.latelierfleursetsens.fr`, puis activer Enforce HTTPS lorsqu'il devient disponible.

L'administration MyBusiness reste sur https://mybusiness.latelierfleursetsens.fr
